# FinFlock project instructions

Use **FinFlock** as the framework's display name, `finflock` as the Python package and distribution name, and `FINFLOCK` for environment-variable prefixes. The repository is named `FinFlock`.

Keep public commits anonymous and keep author names, personal handles, credentials, personal filesystem paths, saved model outputs, and experiment-result artifacts out of this release. Tessera files under `dataset/tessera/` are dataset inputs.

Preserve the scientific implementation, numerical configuration, dataset record IDs, joins, timestamps, and split assignments during naming or documentation changes. Update dataset checksums when a published data file changes.

Run the relevant tests and scan the current source, filenames, and decoded dataset strings for obsolete framework names before publishing a rename. Do not rewrite published Git history as part of a routine rename.
